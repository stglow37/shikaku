# 기준 알고리즘: 높이 배열과 기본 면적 상한

## 범위

연구 노트의 1~2단계를 구현한다. 입력은 양의 정수 n, 목적은 n×n 격자의
직사각형 분할에서 등장하는 서로 다른 넓이의 최대 개수 k(n)이다.
같은 넓이는 반복해서 사용할 수 있다. 최적값과 그 값을 달성하는 분할 하나를 반환한다.

Python 표준 라이브러리만 사용한다. 임의의 양의 정수 n에 대해 정의된 정확 탐색이지만,
큰 n에서 실용적인 시간이나 메모리 안에 끝난다는 보장은 없다.
전처리에는 O(n²)번의 곱셈으로 가능한 넓이 집합을 만들며, 탐색은 조합적으로 커진다.

## 1. 상태와 분기

상태는 (h, S, P, A)이다.

- h[i]: i번째 열에서 위쪽부터 연속해서 채워진 높이.
- S: 이미 등장한 넓이 집합. 현재 점수는 |S|.
- P: 현재까지 놓은 직사각형 목록. 증거 분할 복원에 사용한다.
- A = n² - sum(h): 남은 면적.

가장 작은 높이를 r이라 하고, 높이가 r인 첫 열을 c로 선택한다.
c부터 높이가 r인 연속 구간의 길이를 W라 하면,
폭 1..W, 높이 1..n-r인 모든 직사각형을 (r,c)에 놓아 본다.
순서는 폭 오름차순, 같은 폭에서는 높이 오름차순이다.
이미 사용한 넓이도 그대로 허용한다. 배치 후 해당 열의 높이를 올리고 넓이를 S에 추가한다.
각 자식이 독립적인 불변 집합을 사용하므로, 반복 넓이의 되돌리기 오류가 발생하지 않는다.

구현은 재귀 대신 반복자 스택으로 깊이 우선 탐색한다. 형제 상태는 필요할 때 생성하며,
Python의 재귀 깊이 제한에 의존하지 않는다.

## 2. 완전성과 중복 없는 열거

현재 놓인 직사각형들과 일치하는 완성 분할 Q를 하나 고정한다.
첫 빈칸 (r,c)을 덮는 Q의 직사각형 R을 생각하자.

1. r보다 위의 모든 행은 채워져 있으므로 R의 위쪽 경계는 r이다.
2. r행에서 c보다 왼쪽은 채워져 있으므로 R의 왼쪽 경계는 c이다.
3. R이 지나가는 열의 높이는 r보다 작을 수 없다(r이 최솟값).
   r보다 크면 이미 채운 칸과 겹치므로 그 높이는 정확히 r이다.
4. 따라서 R의 폭과 높이는 분기 범위 안에 있고, R을 선택하는 자식이 존재한다.

이 논증을 반복하면 Q에 도달한다. 따라서 비기요틴 분할도 포함한다.
Q에서 첫 빈칸을 덮는 조각은 매번 유일하므로, 같은 완성 분할의 생성 경로도 유일하다.
가지치기를 끄면 모든 분할을 정확히 한 번씩 열거한다.

## 3. 초기 하한과 상한

초기 분할은 연구 노트의 높이 1인 행과 높이 3인 띠 구성이다.
남는 행은 단위 정사각형으로 채운다. 실제 생성된 분할을 별도 검사하고,
그 분할의 실제 넓이 종류 수를 초기 기록 B로 사용한다.

가능한 넓이 집합 A_n = {ab : 1 ≤ a,b ≤ n}을 오름차순으로 저장한다.
가장 작은 넓이부터 더해 n²를 넘지 않는 최대 개수를 전역 상한 U(n)으로 사용한다.
B=U(n)이면 탐색 없이도 정확값이 증명된다.

## 4. 기본 면적 가지치기의 정당성

현재 사용하지 않은 가능한 넓이를 b_1 < b_2 < ...라고 하자.
새로운 넓이 q개가 등장하려면 각 넓이를 갖는 서로 다른 조각이 하나 이상 필요하다.
이 조각들은 겹치지 않으므로 최소한 b_1+...+b_q만큼의 남은 면적이 필요하다.

따라서 q_max = max{q : b_1+...+b_q ≤ A}라 하면
이 상태에서 가능한 최종 점수는 |S|+q_max 이하이다.
|S|+q_max ≤ B이면 더 좋은 해를 만들 수 없으므로 중단한다.
동점 분할을 생략하는 것은 최적값과 증거 하나를 구하는 목적에 맞다.

이 상한은 실제 배치 가능성과 중복 조각의 비용을 무시한다.
가능성을 낙관적으로 평가하므로 안전한 상한이며, 배치 불가능한 넓이가 섞여 있어도
정확성을 해치지 않는다.

## 5. 종료와 반환값

- 탐색 소진: 더 좋은 분할이 없으므로 현재 기록이 정확값이다.
- B=U(n): 전역 상한 달성으로 정확값이다.
- 시간 제한: 현재 증거가 주는 하한과 전역 상한을 반환한다. 둘이 다르면 k는 null이다.

시간 제한은 탐색 중 확인하며 전처리나 개별 상태 계산을 강제로 중단하지 않는다.
따라서 엄밀한 프로세스 실행 시간 제한은 아니다.
--no-prune은 부분 상태 가지치기와 전역 상한 도달에 따른 조기 종료를 모두 끈다.
초기 기록은 유지하지만, 기록 때문에 어떤 분기도 생략하지 않는다.

출력 JSON의 rectangles 좌표는 0부터 시작한다. 각 조각은 row, col, height, width로 표현한다.
nodes는 방문 상태 수, pruned_nodes는 면적 상한으로 중단한 상태 수,
complete_partitions는 실제 방문한 완성 분할 수이다.
초기 구성과 상한만으로 종료하면 nodes=0이며, 이것은 탐색 성능 측정 사례와 구분해야 한다.

## 6. 의도적으로 제외한 개선

중복 넓이 분기 제거, 후보 우선순위 휴리스틱, 메모이제이션, 상태 압축,
대칭 제거, 현재 공간의 모양을 반영한 상한은 적용하지 않는다.
이후 각각의 효과를 비교하기 위한 기준 구현이다.

## 7. 독립 검증

tests/oracle.py의 cell_oracle은 높이 배열을 사용하지 않는다.
모든 위치의 직사각형을 셀 비트마스크로 만들고, 마지막 빈칸을 덮는 후보 중
겹치지 않는 것을 선택해 분할을 전부 열거한다.
초기 구성, 면적 상한, 메모이제이션도 사용하지 않는다.

n=1..4에서 다음을 비교한다.

- 독립 탐색과 기준 탐색의 최적값.
- 가지치기를 끈 높이 배열 탐색과 독립 탐색의 전체 분할 개수.
- 가지치기를 켜고 끈 경우의 최적값.
- 반환된 증거의 영역 이탈, 겹침, 빈칸, 넓이 종류 수.

추가로 노트의 정확값 n=7,8,13, n=1..40의 초기 구성, 시간 제한 결과,
잘못된 입력과 분할을 검사한다. n=7,8,13은 구성과 상한이 일치하므로
주로 초기 구성 및 상한의 회귀 검사이며, 탐색 성능의 증거는 아니다.
CP-SAT은 이 단계에서는 구현하지 않는다. 작은 크기의 독립 완전 열거를 비교 기준으로 삼는다.

## 실행

```powershell
python -m shikaku 5 --output result_n5.json
python -m shikaku 4 --no-prune
python -m shikaku 6 --time-limit 10
python -m unittest discover -s tests -v
python -m experiments.run
```

마지막 명령은 results/ 아래에 새 실험 디렉터리를 만들고 report.json, config.json, sources.json을 저장한다. 기존 결과를 덮어쓰지 않는다.
결과에는 실행 환경, 상·하한, 종료 이유, 방문 상태 수, 실행 시간 및 증거 분할을 저장한다.
시간은 단일 실행의 관측값이며 평균 성능이나 속도 향상에 대한 통계적 주장은 하지 않는다.
