# 보고서 폴더 안내

이 폴더에는 연구 발표문을 작성하기 위한 통합 원고, 절별 상세 초안 및 벡터 그림이 들어 있다. 사람과 AI 편집자는 이 문서를 먼저 읽고 파일의 역할과 남은 작업을 확인해야 한다.

  - 현재의 통합 원고이다.
  - 초록과 1–4절을 포함한다.
  - 상세 초안을 그대로 이어 붙이지 않고 중복을 줄인 축약본이다.
  - 최종 원고를 수정할 때는 이 파일을 우선 편집한다.
- **paper_draft/section1_introduction.md**
  - 간결한 서론의 상세 초안이다.
- **paper_draft/section2_mathematical_bounds.md**
  - 상한 \(U(n)\), 그 점근적 한계 및 \(11/8\) 하한 구성의 상세 증명을 담는다.
- **paper_draft/section3_computation.md**
  - Skyline, CP-SAT, 독립 검증 및 비교·제거 실험의 상세 설명을 담는다.
- **paper_draft/section4_conclusion.md**
  - 결론과 후속 연구 방향의 상세 초안이다.
- **paper_draft/section2_construction.svg**

- **paper_draft/section3_certification.svg**
  - 하한·상한·정확 풀이기·독립 검증의 관계를 설명하는 후보 도식이다.
  - 현재 **complete_report.md**에는 포함하지 않았다. 지면과 가독성을 확인한 뒤 필요할 때 사용한다.

절별 파일은 설명을 보존하기 위한 작업 자료이다. 통합 원고를 수정했다고 해서 절별 파일이 자동으로 갱신되지는 않는다. 중요한 수학적 또는 실험적 내용을 바꾸면 관련 절별 파일과 통합 원고가 서로 모순되지 않는지 확인해야 한다.

## 내용 확인에 사용할 근거

원고의 수치와 주장을 수정할 때는 다음 파일을 우선 확인한다.

- **docs/area_upper.md**: \(U(n)\)의 체 기반 계산과 \(U(n)/n\to\sqrt2\)의 증명
- **docs/baseline.md**: Skyline 완전탐색의 완전성과 가지치기
- **docs/cpsat.md**: 일반 CP-SAT 모형, 상태 해석 및 모델 크기
- **docs/paper_benchmark_results.md**: 비교·제거 실험의 해석
- **results/paper-benchmarks/benchmark-20260927T122244097906Z-d7e35f7c/analysis-final/**: 논문용 최종 집계 자료
- **results/research-20260920/summary.json**: 정확값, 좌표 증거 및 출처의 통합 자료

**results/**의 원자료는 원고를 맞추기 위해 직접 수정하지 않는다. 원고와 원자료가 다르면 원자료와 분석 코드를 먼저 확인한다. 시간 제한 결과는 불가능성의 증거로 해석하지 않으며, 제한된 띠 모형의 최적성도 원래 문제의 최적성으로 표현하지 않는다.

## 3페이지 제한

최종 발표문은 학회 원고 양식으로 **3페이지 이내**에 들어가야 한다. Markdown의 문자 수만으로 페이지 수를 확정할 수 없으므로 다음 절차가 필요하다.

1. 공식 글꼴, 글자 크기, 여백 및 단 수를 적용한 실제 원고로 조판한다.
2. 그림과 표의 캡션, 참고문헌까지 포함한 최종 페이지 수를 확인한다.
3. 3페이지를 넘으면 아래 우선순위에 따라 내용을 줄인다.
4. 축약 후에도 수학적 논증과 계산 결과의 인증 범위가 변하지 않았는지 다시 검토한다.

우선 축약할 내용은 다음과 같다.

1. 3절의 개별 실행시간과 부가적인 실험 해석
2. CP-SAT 힌트의 음성 결과
3. 상한 계산의 중간 설명과 표준적인 \(\pi(x)=o(x)\) 설명
4. 결론에서 앞 절과 반복되는 수치
5. 표의 설명과 본문에서 중복되는 문장

다음 내용은 가급적 보존한다.

- \(k(n)\)의 정의와 문제의 조건
- \(U(n)\)이 유효한 상한인 이유
- \(k(16t)\ge22t-1\) 구성의 행 수, 넓이 수 및 중복 없음의 근거
- 정확값을 좌표 검증과 상한의 일치로 인증한다는 원칙
- \(1\le n\le26\) 및 \(n=33\)의 정확값 범위
- 시간 초과와 제한 모형의 결과를 과도하게 해석하지 않는다는 조건

내용을 줄일 때 문장을 지나치게 길게 합치지 않는다. 짧은 문장과 식·표를 이용해 논리 구조를 유지한다.

## 그림과 표

**section2_construction.svg**는 일반 구성을 설명하는 개략도이다. A–D 영역의 세로 비율은 사용 행 수 \(4t,t,8t,3t\)를 반영하지만, 각 행의 세로 절단 위치는 반복 구조를 보여주기 위한 예시이다. 실제 좌표 증거로 해석해서는 안 된다.

최종 원고에 그림을 넣기 전에 다음 사항을 확인한다.

- 공식 양식의 한 단 또는 두 단 폭에서 글자가 읽히는가
- A–D 색상이 흑백 출력에서도 구별되는가
- 수식과 기호가 본문의 표기와 일치하는가
- 캡션만 읽어도 그림이 개략도임을 알 수 있는가
- SVG의 기본 sans-serif 글꼴이 조판 환경에서 적절히 렌더링되는가

현재 그림이 원고 양식, 인쇄 방식 또는 발표 목적에 적절하지 않으면 새로 그린다. 가능하면 SVG, TikZ 또는 다른 벡터 형식을 사용하고 낮은 해상도의 화면 캡처로 대체하지 않는다. 새 그림에서도 A–D의 행 수와 생성 넓이 수를 바꾸어서는 안 된다.

**section3_certification.svg**는 계산 절차를 설명하지만, 통합 원고에서는 지면을 아끼기 위해 제외하였다. 이를 추가한다면 다른 그림이나 설명을 줄이고 그림 번호와 본문 참조를 다시 맞춘다.

표를 줄일 때는 서로 다른 풀이기의 노드 수를 직접 비교하는 열을 만들지 않는다. Skyline의 방문 상태와 CP-SAT의 분기 수는 의미가 다르다.

## 문체와 표기

- 논문체를 사용하되 과도하게 긴 문장을 피한다.
- 인라인 수식은 <code>\(...\)</code>, 별도 수식은 <code>\[...\]</code> 형식을 사용한다.
- Skyline, CP-SAT, \(U(n)\), \(T(n)\) 등의 명칭을 원고 전체에서 통일한다.
- 그림과 표 번호는 통합 원고 전체에서 연속되도록 관리한다.
- 좌표 증거, 하한, 상한, 정확값을 구분한다.
- 외부 문헌 전체에서의 최초 결과라고 확인되지 않은 내용에는 “최초”, “처음” 등의 표현을 사용하지 않는다.
- 계수 \(4/3\)인 기존 구성이나 소수 개수 추정에 문헌을 인용하려면 출처를 먼저 확인한다.

## 최종 점검 목록

- 모든 수식의 괄호와 수식 구분자가 닫혀 있는가
- 표의 합계가 본문의 합계와 일치하는가
- B 영역에서 \(2t\)개 폭 쌍을 두 개씩 묶어 \(t\)개 행을 만든다는 설명이 남아 있는가
- C와 D 영역의 두 넓이 집합이 각각 \(16t\), \(24t\)를 기준으로 분리된다는 근거가 있는가
- 일반 \(n\)으로 확장할 때 오른쪽과 아래쪽 직사각형이 겹치지 않는가
- 그림 링크와 캡션 및 표 번호가 올바른가
- 정확값과 실험 수치가 최종 집계 자료와 일치하는가
- 공식 양식에서 참고문헌까지 포함해 3페이지 이내인가
- **git diff --check**가 통과하는가

현재 Markdown 원고는 내용 중심의 편집본이다. 실제 제출본을 완성하려면 공식 원고 양식으로 조판하고, 문헌 인용과 페이지 제한 및 그림의 최종 가독성을 다시 확인해야 한다.
